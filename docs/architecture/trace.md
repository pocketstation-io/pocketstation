# Trace — Required Metrics

## Purpose

Every MediaClock component emits trace data. Trace is not optional and not
an afterthought -- it is built into each component from the first PR.

## Required metrics

### Ingress

| Metric | Type | Unit | Description |
|---|---|---|---|
| packets_in | counter | count | total packets pushed |
| packets_out | counter | count | total packets popped as frames |
| late_packets | counter | count | packets arriving after their playout deadline |
| duplicate_packets | counter | count | packets with already-seen sequence numbers |
| dropped_packets | counter | count | packets evicted by capacity or policy |
| missing_packets | counter | count | sequence gaps detected at pop time |
| buffer_depth | gauge | frames | current number of packets in reorder buffer |
| peak_buffer_depth | gauge | frames | high-water mark of buffer_depth |
| target_delay_ms | gauge | ms | current adaptive target delay |
| time_to_first_frame_ns | gauge | ns | time from first push to first pop |

### Egress

| Metric | Type | Unit | Description |
|---|---|---|---|
| frames_emitted | counter | count | total frames released by tick() |
| queue_depth | gauge | frames | current egress queue size |
| peak_queue_depth | gauge | frames | high-water mark of queue_depth |
| pacing_delay_ns | gauge | ns | last observed pacing delay |
| underruns | counter | count | tick() called with empty queue |
| flush_events | counter | count | queue flushes from Gate interrupt |

### Gate

| Metric | Type | Unit | Description |
|---|---|---|---|
| interruption_count | counter | count | total interrupt() calls |
| truncation_count | counter | count | total truncate() calls |
| clear_count | counter | count | total clear() calls |
| last_played_ms | gauge | ms | played_ms from last interrupt |
| gate_flush_events | counter | count | frames drained by interrupt/clear |

### Drift

| Metric | Type | Unit | Description |
|---|---|---|---|
| drift_ppm | gauge | ppm | estimated clock drift rate |
| accumulated_error_ns | gauge | ns | total timing error from drift |
| samples_count | counter | count | observation pairs in window |

### Codec (media-clock-opus only)

| Metric | Type | Unit | Description |
|---|---|---|---|
| plc_frames | counter | count | frames generated by PLC |
| fec_frames | counter | count | frames recovered via FEC/LBRR |
| decode_errors | counter | count | codec decode failures |

## Naming convention (CODE_PROTOCOL LAW 1)

Every metric field carries its unit suffix: `_ms`, `_ns`, `_ppm`, `_pct`, `_count`.
No bare numeric fields.
