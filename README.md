# audio-core

**Organization:** `pocketstation-io`
**Repository:** `pocketstation-io/audio-core`
**v2.3 tier:** Tier 1 — Core Rust Engine
**Activation phase:** Phase 0
**Language/package:** Rust Cargo workspace
**Release strategy:** SemVer, `cargo-release --workspace`; first publish at Phase 2 entry (v2.3 §14.5; deferred per AUDIO-014)

Rust Cargo workspace that provides the PocketStation Tier 1 audio core. This is
an independently releasable unit — it is not merged into a monorepo.

Phase 0 is **COMPLETE** as of 2026-05-20.

- 26 tests pass across 6 crates.

- `cargo clippy --workspace --all-targets -- -D warnings` clean.
- All exit criteria met per v2.3 §15 Phase 0 section.

## Crate structure

The workspace contains 7 crates (v2.3 §14.3):

| Crate | Contents |
|---|---|
| `pocketstation-frame` | `AudioFrame`, `AudioBufferPool`, `SampleFormat` |
| `pocketstation-bus` | `FrameBus`, `SpscRingBuffer`, `ClockSync` |
| `pocketstation-graph` | `ProcessorGraph`, `AudioProcessorNode` trait |
| `pocketstation-codec` | `OpusEncoder`, `OpusDecoder`, `JitterBuffer` |
| `pocketstation-route` | `RoutePlan`, `CapabilityModel`, `SourceDescriptor` |
| `pocketstation-metrics` | `BusMetrics`, OTEL integration |
| `pocketstation-audio` | Re-exports all above as single entry point |

The workspace also contains `pocketstation-alloccheck` (binary tool for hot-path
allocation verification) and integration tests under `tests/`.

FFI headers for Swift/Kotlin consumption are generated by cbindgen under `ffi/`.

## How to test

```
cargo test --workspace
```

To run with the race detector (requires nightly):

```
RUSTFLAGS="-Z sanitizer=thread" cargo +nightly test --workspace --target x86_64-unknown-linux-gnu
```

To run the sine-wave smoke test:

```
cargo run -p pocketstation-audio --example sine_to_wav
```

## Phase 2 roadmap

Per v2.3 §14.5 and §15:

1. First crates.io publish of `pocketstation-audio` v0.1.0, after the Phase 1
   relay demo validates the API surface.
2. Opus real bindings via `libopus-sys` (burn the Opus MOCK).
3. ClockSync PI controller per AUDIO-006.
4. DHAT CI integration to enforce zero per-frame heap allocation.

sdk-ios wraps audio-core via XCFramework FFI (cbindgen-generated headers). It
cannot be created until v0.1.0 is published. See AUDIO-014.
